# BetterNilam
Integrates with ChatGPT to generate books. Then interacts with Nilam API to automatically "read" (submit) books to Nilam system. Hence, book worm.

> [!NOTE]
> Time flies. I'm not involved in Malaysia education system anymore.
>
> Hence, this project is **permanently** archieved. No more updates.

> [!NOTE]
> This project **ONLY** works in old Nilam system.
